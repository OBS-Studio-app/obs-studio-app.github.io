Update guide

How to update OBS Studio on Windows — latest version guide

To update OBS Studio on Windows, use the built-in update check: Help → Check for Updates. Or download the new installer from obsproject.com and run it over the existing installation. Settings, scenes and plugins are preserved.
How to update

Update OBS Studio on Windows

  • 1

    Method 1 — built-in update

    Help → Check for Updates. If an update is available, OBS prompts you to install it. Click Update and restart.

  • 2

    Method 2 — manual update

    Download the new installer from download page and run it over the existing OBS installation. Your scenes and settings are preserved.

  • 3

    Method 3 — winget

    PowerShell
    PS> winget upgrade OBSProject.OBSStudio
FAQ

Update questions

Will updating OBS delete my scenes and settings?

No. OBS scenes, profiles and settings are stored in %APPDATA%\obs-studio\ which the installer never modifies. Your scenes, stream keys, audio settings and everything else are preserved after an update.

OBS plugins stopped working after update

Major OBS updates sometimes break plugin compatibility. Check each plugin's GitHub page for an updated version. If a plugin is incompatible, it will be listed in OBS → Help → Log File as "Failed to load module".
