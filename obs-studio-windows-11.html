Windows 11

OBS Studio on Windows 11 — install guide & common fixes

OBS Studio 31.x is fully compatible with Windows 11. The main Windows 11 specific issues are SmartScreen blocking the installer and Windows Gaming Features (Xbox Game Bar, Game Mode) interfering with capture.
Install on Windows 11

Install OBS Studio on Windows 11

  • 1

    Download and run installer

    Get OBS-Studio-31.0.3-Windows.exe. SmartScreen may appear — click More info → Run anyway.

  • 2

    Disable Xbox Game Bar if capturing games

    Windows 11 Xbox Game Bar can conflict with OBS game capture. Settings → Gaming → Xbox Game Bar → disable "Open Xbox Game Bar". Or add OBS to the Game Mode exclusion list.

  • 3

    Use Windows Graphics Capture method

    For Display Capture: in source properties, set Capture Method to Windows Graphics Capture. This is the most reliable method on Windows 11.

FAQ

Windows 11 questions

Does OBS Studio work on Windows 11?

Yes. OBS Studio 31.x is fully compatible with Windows 11 and Windows 11 ARM. Install the standard Windows installer. The main thing to know is that Display Capture works best with the Windows Graphics Capture method on Windows 11.
